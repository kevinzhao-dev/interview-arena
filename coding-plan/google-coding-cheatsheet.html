通用解題流程

framework

面試時不要拿到題就寫 code。每一題都照這六步走，把對話結構化，interviewer 才知道你會怎麼思考。

STEP 1

Clarify 題目

  • input size?
  • 有 duplicate? 負數?
  • sorted? directed? weighted?
  • return value 還是 path?
  • 可以修改 input 嗎?
STEP 2

先講 brute force

說出 baseline 與其複雜度，再說明為什麼要優化。
例：O(n²) 太慢，n=10⁵ 需要 O(n) 或 O(n log n)

STEP 3

用 keyword 判斷 pattern

  • contiguous → window / prefix
  • shortest path → BFS
  • dependency → topo sort
  • max/min/count + overlap → DP
STEP 4

定義 invariant / state

  • Window: [l,r] 維持什麼?
  • Graph: visited 何時 mark?
  • DP: dp[i] 代表什麼?
STEP 5

寫 code

核心通常 20–30 行。clean、robust、處理 edge cases。不要寫太長。

STEP 6

複雜度 + 測試

  • empty / single element
  • duplicates / negatives
  • disconnected / cycle
  • large input
核心原則
Pattern matching > 記題目。每題刷完逼自己回答:這題是哪個 pattern? 為什麼適用? 同 pattern 的另一題我能寫嗎?
01

Array / String + HashMap · Two Pointers · Window · Prefix

topic 01 / 03

最高頻基礎 topic。很多其他題目也會包在 array / sequence 裡面，不熟這個其他都別想。

1.1Pattern 對應表

Signal → Solution → Complexity
題目訊號優先想到典型 Big-O
找 pair / existence / frequencyHashMap / HashSetO(n)
sorted array / palindrome / mergeTwo PointersO(n)
contiguous subarray / substringSliding Window / Prefix SumO(n)

1.2看到 array/string 題，先問自己 5 個問題

  1. 是否要保持原本順序? 要 → 不能 sort，考慮 hash / window / DP · 不要 → sort 可能簡化
  2. 是否要求 contiguous? 是 → sliding window / prefix sum · 否 → subsequence / subset / DP / greedy
  3. 是否有負數? 有 → sliding window 通常失效，prefix sum + hash · 全正數 → sliding window 成立
  4. 是否只需要 existence? 是 → HashSet · 需要 index / count → HashMap
  5. input 是否 sorted? 是 → two pointers / binary search

1.3核心 Templates

C++ conventions
所有範例假設 #include <bits/stdc++.h> 與 using namespace std;，為節省篇幅省略 include。範例使用 C++17 (structured bindings auto [a,b]、if constexpr 可用)。

HashMap · Two Sum 類

用空間換時間，把過去看過的資訊存起來。

cpptwo_sum.cpp
vector<int> twoSum(vector<int>& nums, int target) {
    unordered_map<int, int> seen;  // value -> index

    for (int i = 0; i < (int)nums.size(); ++i) {
        int need = target - nums[i];
        if (seen.count(need))
            return {seen[need], i};
        seen[nums[i]] = i;
    }
    return {};
}

Sliding Window · 可變長度

適用 longest / shortest substring · 條件可以用移動 left 修復。

cppsliding_window.cpp
int slidingWindow(const string& s) {
    unordered_map<char, int> count;
    int left = 0, ans = 0;

    for (int right = 0; right < (int)s.size(); ++right) {
        count[s[right]]++;

        // while window invalid, shrink left
        while (!isValid(count)) {
            count[s[left]]--;
            left++;
        }

        ans = max(ans, right - left + 1);
    }
    return ans;
}

Prefix Sum + HashMap

核心公式: sum(i..j) = prefix[j] - prefix[i-1]。若 prefix[j] - prefix[i-1] = k，則 prefix[i-1] = prefix[j] - k。

cppsubarray_sum.cpp
int subarraySum(vector<int>& nums, int k) {
    int prefix = 0, ans = 0;
    unordered_map<int, int> freq;
    freq[0] = 1;

    for (int x : nums) {
        prefix += x;
        if (freq.count(prefix - k))
            ans += freq[prefix - k];
        freq[prefix]++;
    }
    return ans;
}

Two Pointers

cpptwo_pointers.cpp
vector<int> twoPointers(vector<int>& nums, int target) {
    int left = 0, right = (int)nums.size() - 1;

    while (left < right) {
        int cur = nums[left] + nums[right];
        if (cur == target) return {left, right};
        else if (cur < target) ++left;
        else --right;
    }
    return {};
}

topic 02 / 03

2.2Graph 解題流程

  1. 確認 graph 類型 · directed/undirected · weighted/unweighted · cyclic/acyclic · connected/disconnected
  2. 選 representation · adjacency list (常用) · matrix/grid (用 row,col 當 node) · edge list (Union-Find / Bellman-Ford)
  3. 確認 visited 時機 · BFS: 入 queue 時 mark · DFS: 進入 function 時 mark
  4. 確認答案類型 · count components? · shortest distance? · path exists? · topo order? · detect cycle?

2.3核心 Templates

Grid BFS · 最短路徑

Invariant: 第一次到達某個 node 時，就是最短距離 (只適用 unweighted)。

cppbfs_grid.cpp
int bfsGrid(vector<vector<int>>& grid,
            vector<pair<int,int>>& starts) {
    int m = grid.size(), n = grid[0].size();
    queue<tuple<int,int,int>> q;
    vector<vector<bool>> visited(m, vector<bool>(n, false));

    for (auto [r, c] : starts) {
        q.push({r, c, 0});
        visited[r][c] = true;
    }

    int dirs[4][2] = {{1,0},{-1,0},{0,1},{0,-1}};

    while (!q.empty()) {
        auto [r, c, dist] = q.front(); q.pop();
        // if (target) return dist;

        for (auto& d : dirs) {
            int nr = r + d[0], nc = c + d[1];
            if (nr < 0 || nr >= m || nc < 0 || nc >= n) continue;
            if (visited[nr][nc]) continue;
            if (grid[nr][nc] == 1) continue;
            visited[nr][nc] = true;
            q.push({nr, nc, dist + 1});
        }
    }
    return -1;
}

DFS · Connected Components

cppdfs_components.cpp
int countComponents(unordered_map<int, vector<int>>& graph) {
    unordered_set<int> visited;

    function<void(int)> dfs = [&](int node) {
        visited.insert(node);
        for (int nei : graph[node])
            if (!visited.count(nei)) dfs(nei);
    };

    int ans = 0;
    for (auto& [node, _] : graph) {
        if (!visited.count(node)) {
            ans++;
            dfs(node);
        }
    }
    return ans;
}

Topological Sort · Kahn's BFS

判斷點: 有向圖 + dependency + 要 valid order。若 len(order) != n → 有 cycle。

cpptopo_sort.cpp
vector<int> topoSort(int n, vector<pair<int,int>>& edges) {
    vector<vector<int>> graph(n);
    vector<int> indeg(n, 0);

    for (auto& [a, b] : edges) {
        // b -> a means a depends on b
        graph[b].push_back(a);
        indeg[a]++;
    }

    queue<int> q;
    for (int i = 0; i < n; ++i)
        if (indeg[i] == 0) q.push(i);

    vector<int> order;
    while (!q.empty()) {
        int node = q.front(); q.pop();
        order.push_back(node);
        for (int nei : graph[node])
            if (--indeg[nei] == 0) q.push(nei);
    }

    return (int)order.size() == n ? order : vector<int>{};
}

Union-Find · DSU

cppunion_find.cpp
class DSU {
public:
    vector<int> parent, rnk;

    DSU(int n) : parent(n), rnk(n, 0) {
        iota(parent.begin(), parent.end(), 0);
    }

    int find(int x) {
        if (parent[x] != x)
            parent[x] = find(parent[x]);
        return parent[x];
    }

    bool unite(int a, int b) {  // `union` is a keyword
        int ra = find(a), rb = find(b);
        if (ra == rb) return false;
        if (rnk[ra] < rnk[rb]) swap(ra, rb);
        parent[rb] = ra;
        if (rnk[ra] == rnk[rb]) rnk[ra]++;
        return true;
    }
};

Dijkstra · 正權重最短路徑

cppdijkstra.cpp
vector<int> dijkstra(int n,
                     vector<tuple<int,int,int>>& edges,
                     int source) {
    vector<vector<pair<int,int>>> graph(n);
    for (auto& [u, v, w] : edges)
        graph[u].push_back({v, w});

    vector<int> dist(n, INT_MAX);
    dist[source] = 0;

    // min-heap of (distance, node)
    priority_queue<pair<int,int>,
                   vector<pair<int,int>>,
                   greater<>> heap;
    heap.push({0, source});

    while (!heap.empty()) {
        auto [d, node] = heap.top(); heap.pop();
        if (d > dist[node]) continue;

        for (auto& [nei, w] : graph[node]) {
            int nd = d + w;
            if (nd < dist[nei]) {
                dist[nei] = nd;
                heap.push({nd, nei});
            }
        }
    }
    return dist;
}

Dynamic Programming

topic 03 / 03

很多人最怕但 Google 值得準備。DP 解 optimization problem，靠大量練習辨識 pattern，不要跳過。

3.1Pattern 對應表

Signal → DP Type
題目訊號優先想到備註
max / min / count waysDPcore signal
can / cannotBoolean DPbool[]
choices at each stepRecursion + memotop-down
overlapping subproblemsDPdefining
sequence / string comparison2D DPO(mn)
choose or skip itemKnapsack DP0/1 vs unbounded
buy / sell / hold statesState Machine DPfew states
interval merge / burst / palindromeInterval DPO(n³)
subset with bitmaskBitmask DPn ≤ 20

3.2DP 解題六步 · 逼自己寫出來

  1. State · dp[i] 是什麼? dp[i][j] 是什麼?
  2. Transition · dp[i] 從哪些 smaller states 轉移?
  3. Base Case · dp[0]? empty string / empty array 怎麼處理?
  4. Order · i 從小到大? interval length 從小到大?
  5. Answer · dp[n]? max(dp)? dp[0][n-1]?
  6. Optimization · 能不能從 O(n²) space 降到 O(n)?

3.3核心 Templates

Top-down Memoization · 面試最快推導

cppmemo.cpp
int solve(vector<int>& nums) {
    int n = nums.size();
    vector<int> memo(n + 1, -1);

    function<int(int)> dp = [&](int i) -> int {
        if (i >= n) return 0;
        if (memo[i] != -1) return memo[i];

        int take = nums[i] + dp(i + 2);
        int skip = dp(i + 1);
        return memo[i] = max(take, skip);
    };

    return dp(0);
}

Bottom-up 1D DP · House Robber Space-Optimized

cpphouse_robber.cpp
int houseRobber(vector<int>& nums) {
    int prev2 = 0, prev1 = 0;

    for (int x : nums) {
        int cur = max(prev1, prev2 + x);
        prev2 = prev1;
        prev1 = cur;
    }
    return prev1;
}

2D String DP · LCS

cpplcs.cpp
int longestCommonSubsequence(const string& a,
                             const string& b) {
    int m = a.size(), n = b.size();
    vector<vector<int>> dp(m + 1, vector<int>(n + 1, 0));

    for (int i = 1; i <= m; ++i) {
        for (int j = 1; j <= n; ++j) {
            if (a[i-1] == b[j-1])
                dp[i][j] = dp[i-1][j-1] + 1;
            else
                dp[i][j] = max(dp[i-1][j], dp[i][j-1]);
        }
    }
    return dp[m][n];
}

0/1 Knapsack · Subset Sum

核心: 0/1 容量從右往左跑 (避免重複用) · unbounded 從左往右跑 (可重複用)。

cpppartition.cpp
bool canPartition(vector<int>& nums) {
    int total = accumulate(nums.begin(), nums.end(), 0);
    if (total % 2) return false;

    int target = total / 2;
    vector<bool> dp(target + 1, false);
    dp[0] = true;

    for (int x : nums)
        for (int s = target; s >= x; --s)  // 0/1: right -> left
            dp[s] = dp[s] || dp[s - x];

    return dp[target];
}

Coin Change · Unbounded Knapsack

cppcoin_change.cpp
int coinChange(vector<int>& coins, int amount) {
    const int INF = INT_MAX;
    vector<int> dp(amount + 1, INF);
    dp[0] = 0;

    for (int a = 1; a <= amount; ++a) {
        for (int coin : coins) {
            if (a >= coin && dp[a - coin] != INF)
                dp[a] = min(dp[a], dp[a - coin] + 1);
        }
    }
    return dp[amount] == INF ? -1 : dp[amount];
}

State Machine DP · Stock Trading

hold: 手上有股票時的最大 profit · cash: 沒股票時的最大 profit。

cppstock.cpp
int maxProfit(vector<int>& prices) {
    int hold = INT_MIN, cash = 0;

    for (int price : prices) {
        int newHold = max(hold, cash - price);
        int newCash = max(cash, hold + price);
        hold = newHold;
        cash = newCash;
    }
    return cash;
}
